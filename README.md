# 🛒 E-Commerce Website (Django + React)

A full-stack E-commerce web application built using **Django REST Framework** and **React.js**.  
The project includes user authentication, product management, cart, orders, payments, and an admin dashboard.

---

## 🚀 Tech Stack
| Area | Technology |
|-------|------------|
| Frontend | React.js, HTML, CSS, JavaScript |
| Backend | Django, Django REST Framework |
| Database | MySQL / MongoDB |
| Authentication | JWT (JSON Web Tokens) |
| Tools | Git, GitHub, VS Code |

---

## ✨ Features
- User & Admin Authentication
- Product listing, filtering & searching
- Add to Cart / Remove from Cart
- Checkout & Order placement
- Online Payment Integration
- Order status tracking
- Admin dashboard for product & order management
- REST APIs with Django
- Responsive UI using React
